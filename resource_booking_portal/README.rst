This addon enables portal users to create resource bookings directly
from the customer portal when they have the appropriate permissions.
Newly created bookings will remain in a pending state and require manual
confirmation by administrators.

   :local:

Usage
=====

Portal Booking Process
----------------------

Prerequisites
~~~~~~~~~~~~~

1. **Portal User Setup**: Ensure you have a portal user with the
   **"Create booking from portal"** option enabled.

-  This option is available on the **Access Rights** page
-  Only visible for users in the portal user group

Creating a Booking
~~~~~~~~~~~~~~~~~~

1. **Login**: Sign in with your portal user credentials

2. **Navigate to Bookings**:

-  Go to **Portal > Home**
-  Click on **Bookings**
-  Select the **"Create Booking"** button

3. **Fill Booking Form**:

-  A pop-up form will appear
-  **Required fields**:

   -  Subject
   -  Type

-  **Optional fields**:

   -  Description

4. **Schedule Appointment**:

-  Click **"Confirm"**
-  Assign a date with your commercial representative
