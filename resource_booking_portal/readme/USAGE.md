1.  You need a portal user with the "Create booking from portal" option
    active.
2.  You can find this option on the "Access Rights" page, but only if
    the user belongs to the portal user group.
3.  Log in with the user mentioned above.
4.  Go to **"My Account."**
5.  In **"My Account,"** you will find a new section called
    **"Actions."**
6.  In this section, there is a button to access the **create booking
    form.** When you create a booking with this form, you must select
    the **subject** and **type**. The **description** is optional.
7.  When you use the **"Continue"** button, you can assign a date with
    your commercial representative.
